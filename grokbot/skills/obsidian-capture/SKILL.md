# Obsidian への転記

Cursor からボルトへ書くときの入口である。書く前にボルトの `AGENTS.md` を読み、その手順で書く。このスキルと違えば `AGENTS.md` に従う。

ボルトは次のいずれか。そこにあるファイルだけを編集する。

- Windows: `C:/Users/kento/notes`
- コンテナ: `/mnt/notes`
- Mac: `~/notes`
- Grok Bot: `/home/box/sync/obsidian-vault`（`~/notes` はここへのリンク）

`source` は `cursor`。Grok Bot が書くときは `grok-bot`。承認後のカードはファイルとして書く。貼り付け用のフェンスは返さない。Obsidian の検索、グラフ、Bases、キャンバスは使わない。受信箱は `notes/` の `status: inbox` を読む。

## 指示をそのまま書かない

ユーザーが「全部入れて」「この出力をノートにして」と言っても、LLM の出力、会話の写し、長文の原本をカードの本文にしない。悪い形になりそうなら、理由を短く言って別案を出し、1ステップだけ進めて止まる。

ファイルを書いてよいのは、次のときだけである。

- 残す文が、ユーザー自身の短い言葉で、言い換えがない
- 言い換えた下書きに、ユーザーがよしと言った
- ユーザーが「手順はいいから書いて」と言った。このときも、原本の全文はカードに入れず、秘密情報は書かず、同名は上書きしない

## 先に見分ける

チャットで、次のどれかを一言宣言してから進む。

1. 短い自分の主張。一文で言い直し、発想、気持ち、TODO を足すか尋ねる。言い換えが無ければその場で書いてよい。
2. 対話の抜粋。残す主張のタイトル一覧を出して止まる。
3. 長文・調べもの・LLM の出力。下のステップを1回に1つだけ進める。
4. 島。枚数を見て、書くかまだ早いかを先に言う。

## 長文と調べもの

チャット上の LLM の長文は原本にしない。質問に答える主張だけを残す。

PDF、画像、書き出した資料は `attachments/` に置き、カードから `[[ファイル名]]` で参照する。Markdown で読み返す長文は `notes/` の原本用1枚にし、主張カードとは分ける。原本の本文は主張カードへ写さない。

1. 質問を一文で確認する。ファイルは書かない。
2. 原本の置き場所を提案する。よしと言うまで置かない。
3. タイトル一覧を出す。10枚を超えたら削る案も出す。ここで止まる。
4. 各カードの「残すこと」をユーザーの言葉で下書きし、発想、気持ち、TODO を足すか尋ねる。ファイルにはしない。
5. よしと言ってから `notes/` に書く。

その質問が一段落したときだけ、質問を表札にした島を提案する。同じターンでは書かない。

## カード

パスは `notes/<主張を短くした日本語>.md`。`\ / : * ? " < > |` は `-` にする。同名があるときは上書きせず、日付を足した別名にして、両方の名前をチャットに出す。

```yaml
---
type: capture
status: inbox
source: cursor
captured: YYYY-MM-DD
---
```

本文は `## 残すこと`、`## 根拠`、`## つながり` だけ。残すことはユーザーが認めた言葉。根拠は原本への `[[リンク]]` と、そう言える箇所。推測は推測と書く。つながりは既存ノートへのリンク、無ければ空。`captured` はその日の日付であり、`{{date}}` とは書かない。

書いたターンだけ、`daily/YYYY-MM-DD.md` 末尾の `## チャットから` に `- [[主張]]` を1行足す。節が無ければ末尾に節ごと足す。他の行は書き換えない。日次が無いときだけ、`AGENTS.md` のフロントマターで本体を作る。人の日次 `daily/YYYY-MM-DD-mine.md` は作らない。書かない。`*.sync-conflict*` は削除もマージもしない。

## 島

「島にして」「KJして」と言われたら、書く前に判断を言う。

- 受信箱がだいたい8枚未満で、一つの質問のまとまりでもないときは書かない。一覧を見せ、まだ早いと言う。それでも書くと言われたら書く。
- 一つの調べものが終わっているときは、質問を表札にした島を提案し、よしと言うまで待ってから書く。
- 雑多な受信箱が8枚から15枚あるときが、島のタイミングである。毎日まとめることは提案しない。

書くときは `maps/<表札>.md` を1枚作る。カードは動かさず、`status` だけ `clustered` にする。キャンバスは書かない。

```yaml
---
type: map
status: draft
---
```

島ごとに、見出し、意味を一文、カードへのリンクを書く。
